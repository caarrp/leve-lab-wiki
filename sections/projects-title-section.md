It uses a fullwidth divi section that contains a fullwidth header element. 

# Fullwidth Section

The fullwidth section uses 'rennie-kendrick-uo-science-lab.jpg' as a background image. 

Because of the cosmic-wp-v2 theme, there is custom CSS to pull the image across the page. 
it looks like this: 

    width: 82.5vw;
    margin-left: calc(-32vw + 50%);

This is setting the image to fit 82.5% of the viewport, and 
the second line is centering the image. These are kind of arbitrary numbers and you can mess
with them if ever it doesnt fit completely. It is important to use viewport units though so that
these choices are standard for any computer screen that opens the website.
